## Featured Project: SKS Carousel Design Studio

A browser-based visual editor designed for Üsküdar University Health, Culture and Sports Department workflows.

### Highlights

- Multi-slide carousel creation and management
- Protected first and final slides
- Optional continuation preview of the next slide
- Club, logo, and Instagram account matching
- Image positioning, zooming, fitting, filling, and proportional resizing
- Drag-and-drop ordering for middle slides
- Editable headline and vertical title placement
- Post, Story, and Web output formats
- Individual high-resolution PNG export
- Complete carousel export as a single ZIP file
- Automatic device-local project saving
- No server upload for user-added images

### Output Formats

| Format | Resolution |
|---|---:|
| Instagram Post | 1080 × 1350 px |
| Instagram Story | 1080 × 1920 px |
| Web Visual | 800 × 600 px |

[**Open SKS Carousel Design Studio →**](https://pelinaybar.com/apps/sks-carousel/)

## SKS Event Studio V2

A multi-format production tool for preparing weekly student club communications from a single Excel source.

- Excel-based bulk event import
- Shared and synchronized event data across every format
- Mail bulletin, Instagram Post, Story, and weekly summary outputs
- Automatic time-based sorting
- Manual drag-and-drop ordering
- Campus-based institutional color mapping
- Automatic club-logo matching
- Multi-logo support for joint events
- Public-holiday placement in weekly summaries
- PNG and ZIP export
- Local draft saving and version history

[**Open SKS Event Studio V2 →**](https://pelinaybar.com/apps/event-creator-v2/)

## Privacy by Design

- Uploaded images and Excel files are processed inside the browser.
- Project drafts are stored locally on the current device.
- User content is not intentionally transmitted to an application server.
- Clearing browser storage also removes locally saved drafts.
- The website's visual access screen is a user-interface layer, not server-side authentication.
